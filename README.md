# RankUp Chess — Releases

This repository hosts the Windows installer downloads for **RankUp Chess**, an offline chess mastery app by [Stillware Ltd](https://stillwareltd.com).

## Download

Grab the latest installer from the [Releases page](https://github.com/stillware-ltd/rankup-chess-releases/releases/latest).

Current version: **v0.1.6** &mdash; [RankUpChess-Setup-0.1.6.exe](https://github.com/stillware-ltd/rankup-chess-releases/releases/download/v0.1.6/RankUpChess-Setup-0.1.6.exe)

## System requirements

- Windows 10 (version 1809 / build 17763) or later
- 64-bit x86 processor
- ~200 MB free disk space

## SmartScreen notice

The installer is not yet code-signed, so Windows SmartScreen will show a "Windows protected your PC" warning the first time you run it. Click **More info** &rarr; **Run anyway** to proceed.
