# RankUp Chess — Releases

This repository hosts the desktop downloads for **RankUp Chess**, an offline chess academy for kids by [Stillware Ltd](https://stillwareltd.com).

## Download

Grab the latest release from the [Releases page](https://github.com/stillware-ltd/rankup-chess-releases/releases/latest).

- **macOS**: v0.7.0, [RankUpChess-0.7.0-macOS.dmg](https://github.com/stillware-ltd/rankup-chess-releases/releases/download/v0.7.0-macos/RankUpChess-0.7.0-macOS.dmg). Signed with a Developer ID certificate and notarised by Apple.
- **Windows**: a 0.7.0 installer is coming soon.
- **iPhone and iPad**: [App Store](https://apps.apple.com/app/id6806675796)
- **Android**: [Google Play](https://play.google.com/store/apps/details?id=com.stillware.rankup_chess)

## System requirements

- **macOS**: 10.15 (Catalina) or later. Universal binary, Apple Silicon and Intel.
- **Windows**: Windows 10 (version 1809 / build 17763) or later, 64-bit.
